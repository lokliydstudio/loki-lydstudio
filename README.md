# Loki Lydstudio – enkel GitHub Pages-side

## Publiser på GitHub Pages
1. Lag et nytt repo på GitHub, f.eks. `loki-lydstudio`.
2. Last opp innholdet i denne mappen (inkl. `assets/`).
3. Gå til **Settings → Pages**.
4. Velg **Deploy from a branch**.
5. Velg branch `main` og mappe `/ (root)`, trykk **Save**.

Etter noen sekunder/minutter får du en URL (typisk `https://<brukernavn>.github.io/<repo>/`).

## Endre innhold
Åpne `index.html` og oppdater:
- e-post/telefon
- tekst om tjenester/priser
- lenker til sosiale medier
